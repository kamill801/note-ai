Note AI MVP1 Neo Brutalism App Design

1차 MVP는 사용자가 선택한 Neo Brutalism 방향으로 갑니다. 핵심 언어는 방금 저장, 이 부분 저장, 내 생각 말하기입니다. 로그인부터 영상 가져오기, 듣기, 저장, 노트, 자료, 설정까지 전체 앱 페이지를 한 번에 구현 가능한 기준으로 정리했습니다.

Chosen style: Neo Brutalism Main color: Block Lime #dceeb1 Primary CTA: 이 부분 저장 Avoid: 캡처, AI 요약툴, 숨김 YouTube 재생

5-Round Design Loop

이번 보드는 5회 루프를 거쳤습니다. 스타일을 먼저 정한 뒤 전체 페이지를 만들고, 이동 중 사용성, 앱 기능 버튼, 구현 가능성, 가독성까지 검사했습니다.

Loop 5/5
Loop 1

Style lock

Neo Brutalism 채택. 굵은 테두리, offset shadow, Block Lime 액션 컬러를 핵심으로 고정했습니다.

Loop 2

Flow map

로그인 → 영상 가져오기 → 듣기 → 이 부분 저장 → 내 생각 → 노트 → 자료 흐름으로 단순화했습니다.

Loop 3

Screen inventory

앱 버튼마다 도착해야 하는 기능 페이지를 빠짐없이 배치했습니다. 홈, 듣기, 노트, 자료, 설정을 포함합니다.

Loop 4

Usability pass

이동 중 조작을 위해 44px 이상 터치 타깃, 하단 주요 버튼, 한 화면 한 목적 원칙을 적용했습니다.

Loop 5

Implementation audit

React Native/Expo에서 구현 가능한 카드, 버튼, 상태 컴포넌트 단위로 줄이고 DESIGN.md에 계약화했습니다.

Reference fit
Snipd

듣다가 저장

핵심은 한 번의 행동으로 현재 순간을 남기는 것. 우리 화면에서는 “이 부분 저장” 버튼이 담당합니다.

Readwise Reader

근거 있는 노트

YouTube transcript/highlight 흐름을 참고해 노트마다 시간, 근거 구간, 내 생각을 노출합니다.

mymind

정리 부담 없음

사용자에게 폴더/태그 정리를 시키지 않고, 최근 저장/영상별/키워드별로 자동 묶습니다.

Granola

조용한 AI

AI를 전면에 과시하지 않고, 사용자가 남긴 말이 깔끔한 노트가 되는 결과 중심 UX로 둡니다.

Voicenotes

말하고 끝

기록 중 복잡한 설정을 요구하지 않고, 말한 뒤 요약/액션/자료가 한 곳에 생기는 구조를 차용합니다.

영상 가져오기

YouTube 링크 붙여넣기 또는 공유 시트. 등록 후 transcript 처리 상태를 즉시 표시합니다.

03

듣기

공식 YouTube 플레이어를 보이게 유지하고 현재 재생 시간과 저장 버튼을 함께 둡니다.

04

내 생각 말하기

저장 직후 음성 메모를 받습니다. “이거 온보딩에 적용” 같은 의도를 놓치지 않습니다.

05

노트 / 자료

근거 구간, 내 메모, 요약, 적용 아이디어, 검색 키워드, 자료 추천으로 정리합니다.

Final Audit

이 디자인을 실제 MVP 구현에 넘기기 전 마지막 검사 결과입니다.

Pass with notes

채택할 것

  • 굵은 검정 테두리와 offset shadow.
  • Block Lime은 메인 행동과 상태 카드에만 사용.
  • 사용자 언어는 `이 부분 저장`, `방금 저장`, `내 생각 말하기`.
  • 한 화면에는 하나의 주요 행동만.
  • 노트에는 항상 원본 영상, 시간, 근거 구간, 내 생각을 표시.

피할 것

  • `캡처`를 사용자-facing CTA로 쓰지 않기.
  • AI 마법/반짝임/그라데이션으로 결과를 과장하지 않기.
  • Neo Brutalism을 너무 장식적으로 써서 가독성을 해치지 않기.
  • YouTube 플레이어를 숨기거나 오디오 앱처럼 보이게 하지 않기.
  • 온보딩에서 긴 설명을 강요하지 않기.

구현 체크

  • 모든 터치 타깃은 최소 44px.
  • 카드 radius는 0-8px, 전화기 프레임/하단 탭만 크게 둠.
  • 그림자는 `4px/7px solid black offset` 토큰으로 통일.
  • 텍스트는 한국어 줄바꿈을 고려해 여유 폭 확보.

최종 판단

  • 1차 MVP는 Neo Brutalism으로 진행.
  • 개발 전 기준은 `DESIGN.md` Active 버전.
  • 이 HTML은 시각 참조, `DESIGN.md`는 구현 계약.
  • 다음 단계는 구현 전 `PLAN.md` 화면 태스크와 맞추기.
